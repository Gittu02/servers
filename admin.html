Quartz SMP — Admin: Change Server IP

How this works: Saving here updates ip.json in your GitHub repo via the GitHub API. Everyone who opens the site will see the new IP within seconds.






  


How to get a GitHub Token

  1. Go to github.com/settings/tokens/new
  2. Give it any name, e.g. QuartzSMP Admin
  3. Set expiration to No expiration
  4. Under Scopes, tick repo
  5. Click Generate token and paste it in the field above
  6. Click Save Settings to Browser so you don't have to re-enter it

Your token is saved in this browser only (localStorage). It is never sent anywhere except directly to api.github.com.
